# homebrew-tap

Mitch Malone's Homebrew tap — one tap for all projects.

```sh
brew install mitchmalone/tap/beeptui     # TUI beeper (formula)
brew install mitchmalone/tap/launcharr   # app launcher for pirates (cask)
```

Everything here is **generated** by each project's release pipeline on its `v*`
releases — `Formula/beeptui.rb` by [beeptui](https://github.com/mitchmalone/beeptui),
`Casks/launcharr.rb` by [launcharr](https://github.com/mitchmalone/launcharr).
Do not edit by hand; fix the generator, not the output.
